# 从剪藏恢复阅读结构

| 读者要做的事 | 整理后的结构 |
| --- | --- |
| 通过大纲找到一节 | 正文主节从 `##` 开始，子节沿原文关系递进。章节开头的装饰编号交给 Obsidian 自动生成。图注、字段标签和普通加粗行留在所属章节内。 |
| 一次读完一个意思 | 将明确被剪藏拆碎的同一段接回去，原有论点、引文和独立段落各自保留。 |
| 看清条目的关系 | 有顺序的步骤用有序列表，并列要点用无序列表。单独成行的连续序号，下一行是加粗或普通段落时，收成同一条有序列表。保留既有的有效子项、缩进和任务状态。 |
| 比较几个方案 | 字段相同且内容短时可用表格。原文按方案分组且字段较长时用短标题加字段列表，窄侧栏也能读清。方案名、字段名、值与顺序来自原文。字段关系无法确定时保留原段落。 |
| 看图或复制示例 | 图注紧邻对应图片。代码和提示词分别放入适当语言的围栏，图注和解释留在外面。保留链接、代码缩进、字符串及提示词段落。 |

现有表格按各行所属列恢复分隔行。横竖关系完整时才补分隔符，缺失数据保留给用户核对。整理后的主要依据是章节关系、同组信息的归属、原文内容完整以及代码可复制。
