# 提示词和代码

用于判断未围栏代码，或确认程序已经圈出的代码块。能确定的结构由程序处理，模型只对候选返回确认或 keep。

- 代码围栏外，只有不属于 HTML 的标签名才把 `<` 转义成 `\<`，段落和引用保持不动。`video`、`img`、`br` 等 HTML 标签、自动链接、行内代码和已经在围栏里的内容不动。已经转义的不再加一层。
- 独立的「提示词」「提示词示例」「提示词节选」「Prompt」标签后，程序保护紧随的可复制正文。放在引用里的，去掉引用标记后放进 `text` 围栏。图注、结果说明、下一节和图片留在围栏外。
- 围栏使用配对反引号。正文里已有反引号时加长外层。旧的波浪号文本围栏在提示词位置换成反引号。只表示空白的 HTML 实体可去掉，正文里的字符、空格和换行保留。
- `...python`、`...yaml`、`...bash`、`...text` 这类剪藏标记，用围栏包住标记后的连续代码。后面的叙述、结果和图片留在外面。
- 已有围栏保留原有字符和顺序。`fenceLanguage` 来自剪藏时的自动识别。内容能证实另一种语言时，用 `set-code-language` 或在 `reformat-code` 的 `language` 里纠正标签。只纠正标签可以保留代码原样，例如识别误标的 Rust、Go 和 SQL。只有确认是网页行号时才去掉行首数字，清单、日志和代码里的数字保留。
- 剪藏若在代码的每一行之间插入空行，程序删掉这种均匀空行。YAML 只在解析结果保持一致时删空行。能解析的单行 JSON 按两格缩进展开。已有围栏被压成一行或语句粘连时，用 `reformat-code` 恢复能从原文确认的换行和缩进。保留笔误、字符串内部的空格和标点。程序还会核对 JavaScript 和 TypeScript 的语法结构，以及 Python 和 Shell 中影响行为的换行和缩进。拿不准时返回 keep。
- 可解析的单行配置属性片段，例如 `package.json` 中单独摘出的 `scripts`，由程序直接展开。保留原有引号、转义和逗号。
- 排版能否写回取决于该语言的校验规则。暂时无法校验布局的语言可以纠正可确认的标签，正文保留原样。
