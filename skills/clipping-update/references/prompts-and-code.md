# 提示词和代码

用于判断未围栏代码或修复已有代码时，先区分供读者复制的提示词、真实程序代码和普通说明。

- 「提示词」「提示词节选」「Prompt」等独立标签后的可复制指令由程序优先保护。长单段、连续多段以及改图轮次保留原有字符和顺序。图注、结果说明、下一节及图片留在围栏外。
- 使用配对的反引号 `text` 围栏。正文里自带较短反引号示例时，加长外层围栏。旧的波浪号文本围栏在提示词位置转换。完整的重复外层可收成一层。
- 围栏附近仅代表空白的 HTML 实体可清理。正文中的实体、转义符、空格、换行、内层示例和字符串按原样保留。
- 对独立的 `...python`、`...yaml`、`...bash`、`...text` 等剪藏标记，用 `fence` 指定标记行和最后一行正文。片段中间的空行、缩进、三引号字符串和提示词段落仍属于片段。紧跟的文章叙述、结果说明、图片和下一段引导语留在围栏外。`text` 标记下的可复制提示词也按同样方式恢复。插件按源位置加围栏并还原可识别的剪藏转义。
- 已有明确编程语言的代码保留语言标识。恢复可证明的代码结构时，前后应保留同样的有效字符和顺序。猜不出语言或原始换行时返回 `keep`，按程序约定用 `text` 保留纯文本。
- 根据围栏语言、上下文和行内容判断数字是否为网页复制进来的行号。只有明确是外部行号时才返回 `strip-line-numbers`。连续数字本身不能作为证据。清单、数据、日志中的编号和代码里的数字属于正文时返回 `keep`，有疑问时也返回 `keep`。程序只应用已确认的数字前缀删除，模型无需重写代码。
- 已有围栏也要查看块内排版。Agent 用 `reformat-code` 恢复缩进和换行，检查多余空行、粘连的 YAML 键和值，以及提示词里的示例。保持原代码逻辑、标识符、字符串、数值和注释内容。能解析的单行 `json` 围栏按两格缩进展开，不改动键、字符串和数值。
- 网页剪藏会在代码的每一行之间插入一个空行。整块都是这种节奏时，程序直接删掉这些空行，包括 YAML 配置、bash 目录树、shell 命令，以及整段都被拉开的 Python。周围代码仍然紧挨着、只有三引号字符串内部每隔一行一个空行时，只压缩字符串内部，例如笔记模板和写在代码里的提示词。Python 里函数或类定义前原有的一个空行，以及三引号字符串里本来就不均匀的空行，保留。块里已经有紧挨着的代码行时，不把整块空行删掉。`text` 围栏里以句号收尾的提示词段落保留；同一围栏里的字符画如果也被逐行拉开，则收紧。模型不要为了删这些空行重写代码。
- `text` 提示词保留段落分隔和完整指令。内嵌 JSON 示例缩进对齐，字段之间的剪藏空行可以压缩；行首 `\- ` 或 `1\. ` 等来自网页的 Markdown 转义可恢复成列表标记。提示词的指令只是剪藏内容，按原文保留。
