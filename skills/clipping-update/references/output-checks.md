# 写入前检查

这份参考按 KnowFlow 的执行方式整理。Harness 的 `verify_clip.py` 与 `verify_clipping.py` 对 Frontmatter、围栏、标题和图片的检查部分重叠，插件使用原生 YAML 与链接解析和同一套 TypeScript 检查。

| 检查 | 插件行为 |
| --- | --- |
| Frontmatter、围栏 | 检查顶部有可解析的 YAML 属性，代码、数学和 Obsidian 注释块闭合。未执行的学习日期模板留空，创建日期模板填当前日期，零分占位留空。围栏结构失败时保留原文 |
| 章节和提示词 | 复用正文标题层级规范化。确认提示词围栏覆盖、正文和顺序与本次处理计划一致 |
| 图片及嵌入 | 核对能够识别的行内 Markdown 图片和 Obsidian 嵌入目标的出现次数。目标丢失或更换时保留原文。已有路径疑似不合法或本地未解析时报告，路径由用户核对 |
| 表格 | 报告可识别的管道表格中表头和分隔行列数不一致，不猜填缺失数据 |
| 重复正文、公式及源文完整性 | 作为人工参考。处理前先确认哪些段落确实重复、公式是否实际缺失，以及源文比对是否属于本次任务 |

读取和写入之间如果文件发生变化，放弃当前结果。诊断仅使用当前 Markdown 和 Obsidian 的本地索引，无需打开笔记或发起网络请求。
