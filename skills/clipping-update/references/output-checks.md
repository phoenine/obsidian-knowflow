# 写入前检查

写回前由程序检查当前 Markdown。失败则整篇保留原文。警告只提示，不回滚。

| 检查 | 处理 |
| --- | --- |
| Frontmatter | 顶部 YAML 必须能解析。未执行的学习日期留空，创建日期填当天，零分占位留空 |
| 围栏 | 代码、数学和注释块必须闭合，否则保留原文 |
| 原始 HTML | 围栏外不属于 HTML 的标签名把 `<` 转义成 `\<`。`video` 等 HTML 标签保留 |
| 图片和嵌入 | 原有目标必须仍在。丢失或被改掉则保留原文。路径不合法，或本地找不到时，只报告 |
| 表格 | 表头和分隔行列数不一致时报告，不补单元格 |

读写之间文件有变化，就放弃这次结果。检查只使用当前 Markdown 和 Obsidian 的本地链接索引。
