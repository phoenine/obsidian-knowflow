# 图片恢复边界

- 只处理笔记中已经引用的图片。先查笔记相对路径和 Vault 路径，查找可唯一定位的本地附件。保留已经正常的链接、替代文字、宽度和外层跳转链接。
- 直链失效时按来源重试。微信公众号图片使用 `https://mp.weixin.qq.com/` 作为 Referer，完整保留图片路径和查询参数。其他来源可尝试原文地址和站点根地址。保存前检查实际文件头和解码结果。
- 微信可能返回能解码的防盗链占位图。对可疑小预览，只有来源请求得到尺寸明显不同的有效大图才替换。小体积横条按疑似占位图保留原链接。小图体积本身不代表失效。
- 需要回源时，每次整理最多读取一次 Frontmatter 中的原文网址。从公众号正文容器或通用文章正文提取图片，优先使用懒加载的 `data-src` 等来源。只采用唯一吻合的图片路径、图注或邻近文字，无法确认就保留原链接并报告。
- 下载结果写到 Obsidian 当前的附件位置，再替换笔记中的嵌入目标。需要登录、验证码或网页运行后才能获取的图片超出静态读取范围，保留原链接交给用户处理。
