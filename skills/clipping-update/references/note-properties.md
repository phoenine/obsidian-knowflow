# 笔记属性

整理时重写简要描述、阅读价值、分类和标签。没有生成出简要描述时清空该字段。阅读价值、分类或标签这次没有给出新值时，保留原值。

- 简要描述是属性栏里的检索摘要。用一句书面中文写明文章的对象、做法和解决的问题，例如「用事件日志保存原始记录，再用派生索引提供查询」。不要复述标题，不要摘抄导语或金句，也不要写成感叹、口号或对读者说话。不使用叹号、问号、表情和语气词。
- 阅读价值按 1–5 评分。1 为广告、严重过时或无实质内容。2 为浅层资讯和营销。3 为有细节的普通教程或观点。4 为深度技术分析和工程经验。5 为可反复查阅的长期参考。
- 分类只能从给出的选项里选一个，作为建议目录。不要据此移动文件。
- 标签选择 1–6 个可检索的主题，多词用连字符连接。使用文章自己的主题，不用来源平台，也不用文章没有覆盖的主题。
